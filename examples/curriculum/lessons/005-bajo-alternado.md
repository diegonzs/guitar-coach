## Pinza

Una **pinza** es tocar el bajo con el pulgar y una cuerda aguda con otro dedo
**al mismo tiempo**, como si pellizcaras.

```alphatex exercise=bajo-am
\ts 4 4
\voice // agudos: blancas, se dejan sonar mientras el pulgar alterna
:2 1.2 0.1 | 1.2 0.1
\voice // bajo alternado
:4 0.5 2.4 0.5 2.4 | 0.5 2.4 0.5 2.4
```
